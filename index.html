SurveyDoctor

For REDCap surveys

Cleaner data starts with a cleaner instrument.

SurveyDoctor’s job is to help your survey collect better data — by reviewing the metadata you already have, showing where the instrument could be stronger, and helping you make those improvements. Along the way it makes useful REDCap patterns visible so you can apply them consistently, instead of rediscovering them field by field.

It is a desktop app that sits next to REDCap, not a replacement for it. You still decide what goes back into the project.

Stays on your computer

The dictionary is opened locally. If you connect to REDCap, only metadata is requested — not records, not participants. The API token lives in memory for that session and is not saved to disk. Nothing is written back to the server.

What it is for

Built for REDCap admins, data managers, and anyone who has inherited a complicated instrument. You load a data-dictionary CSV or connect to a project and pull the current metadata. SurveyDoctor reviews that dictionary — branching, embedded text, hidden fields, missing choices, and similar design problems — and shows each finding next to the field it belongs to, with a plain-language explanation of why it matters.

The point is not a red/green score. Some “issues” are intentional; you can accept those so they stop shouting. Others are real improvements: a branching expression that will hide a question you still need, piped text that never appears, a pattern used in one form and forgotten in the next. Optional Edit mode lets you make small local patches and export a CSV. That is not a second Online Designer — you choose what, if anything, goes back into REDCap.

Click a field and the table, the minimap, and the diagnostics stay together. That is how you actually review a large instrument, instead of hopping through Online Designer one variable at a time.

What it is not

It does not open records or any participant data. It does not upload changes to REDCap for you. It is not a survey platform, and it is not open source — SurveyDoctor is a paid product, currently in pre-release.

Installers are unsigned for now. On Windows 11, SmartScreen will warn you; choose More info, then Run anyway. On a Mac, right-click the app and choose Open the first time. Apple Silicon only at the moment (Windows is x64). Hospital IT may block unsigned software; if that is a hard stop, say so in the email.
