Desktop workbench

Diagnostics for REDCap data dictionaries

Load a dictionary. Select a field. The table, the minimap, and the issue list move together. Accept what is intentional. Export a CSV patch when it is not.

Built for REDCap admins, data managers, and people who live in large instruments. Not a REDCap replacement. Not Online Designer.

Request access No public download yet. Email if you have a dictionary you want to run through it.

On your machine

Dictionaries stay local. REDCap API tokens stay in memory for the session and are not written to disk. No records. No PHI. No write-back to the server.

Does

  • CSV ingest Standard REDCap data-dictionary export.
  • REDCap API metadata content=metadata only. Token is session-only.
  • Structure diagnostics Branching, embedding, hidden fields, catalog + Accept.
  • Optional Edit Patch a working copy and export CSV. Not a form builder.

Does not

  • Records or PHI No participant data. No DuckDB. No query of values.
  • Write-back to REDCap You export a CSV and upload it yourself, if you choose.
  • Replace Online Designer Authoring is surgical patches, not a second designer.
  • Open source Proprietary paid product. Source is not on GitHub.
